[MCQ / OBJECTIVE GRADING RULE]: An answer is CORRECT if EITHER the selected option identifier (e.g. "c)") OR the option label text matches the correct answer. Award full marks unless BOTH the identifier AND the text are wrong. (Note: MCQ-typed questions are graded deterministically in code and never reach this rubric; this applies only to objective-flavoured items routed to the model.)

GRADING DIRECTIVES — OBJECTIVE / MCQ / ASSERTION-REASON / TRUE-FALSE

1. BINARY SCORING: award either 0 or the FULL mark. No partial credit, and no negative marking.
2. The answer key is the sole authority for which option is correct.
3. CORRECT if EITHER the selected option identifier (a, (b), C., a bare letter) OR the option text
   matches the key. Award 0 only when BOTH are wrong, or when nothing was actually selected.
4. Compare ignoring case, brackets, punctuation, whitespace and trivial formatting. Equivalent
   forms are equal (182/3 pi = 182pi/3; 0.5 = 1/2).
5. IGNORE rough work, scratch calculations and crossed-out attempts. Grade the student's
   deliberate FINAL selection, wherever in the text it appears. If one option is struck through
   and another marked, grade the one NOT crossed out.
6. BENEFIT OF THE DOUBT: if a reasonable reading of an ambiguous response matches the key, award
   the mark. Working shown beside the option never costs marks.
7. An answer that shows correct working for THIS question but selects no option, or selects the
   wrong one, still scores 0 — but it is NOT off-topic. Only flag off-topic when the content
   belongs to a different question entirely.
